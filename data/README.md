# Data

The dataset is not committed to the repo.

1. Download **Dry Bean Dataset** from the UCI Machine Learning Repository
   (https://archive.ics.uci.edu/dataset/602/dry+bean+dataset), or from Kaggle.
2. Place the file in `data/raw/` as `Dry_Bean_Dataset.xlsx` (UCI) or `.csv` (Kaggle).

**Citation:** Koklu, M. and Ozkan, I.A. (2020). Multiclass classification of dry beans using
computer vision and machine learning techniques. *Computers and Electronics in Agriculture*, 174, 105507.

| Property | Value |
|---|---|
| Samples | 13,611 |
| Features | 16 (area, perimeter, axis lengths, aspect ratio, eccentricity, convex area, equivalent diameter, extent, solidity, roundness, compactness, ShapeFactor1-4) |
| Target | `Class`: Seker, Barbunya, Bombay, Cali, Dermason, Horoz, Sira |
